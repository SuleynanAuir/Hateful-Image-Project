# 修复依赖冲突警告

## 问题
安装timm等库后出现警告：
```
ERROR: pip's dependency resolver does not currently take into account all the packages that are installed.
fairseq 0.12.2 requires omegaconf<2.1, which is not installed.
```

## 原因
之前为了安装fairseq，我们卸载了omegaconf 2.3.0，但安装timm等库时没有重新安装兼容版本的omegaconf。

## 解决方案

### 方法1: 在notebook中安装（推荐）

在notebook中运行：
```python
! pip install "omegaconf>=2.0.5,<2.1"
```

### 方法2: 在命令行中安装

```bash
conda activate hateful-image-ofa
pip install "omegaconf>=2.0.5,<2.1"
```

## 验证

安装后验证：
```python
import omegaconf
import timm
import numpy as np
print(f"omegaconf: {omegaconf.__version__}")  # 应该是 2.0.5 或 2.0.6
print(f"numpy: {np.__version__}")  # 应该是 1.26.x
print(f"timm: installed")
```

## 重要提示

⚠️ **安装完成后，必须重新运行notebook的导入代码！**

由于timm和numpy是新安装的，notebook的kernel可能还在使用旧的模块状态。需要：

1. **重启Kernel**（推荐）
   - 在Jupyter Notebook菜单：`Kernel` → `Restart Kernel`
   - 然后重新运行所有cell

2. **或者重新运行导入代码**
   - 重新运行第3个cell（导入OFA模块的代码）
   - 如果还有错误，重启kernel

## 完整安装步骤总结

1. ✅ 运行第1个cell（添加OFA路径）
2. ✅ 运行第4个cell（安装timm等依赖）
3. ✅ 安装omegaconf（解决依赖冲突）
4. ⚠️ **重启Kernel**
5. ✅ 重新运行第1个cell
6. ✅ 重新运行第3个cell（导入代码）

如果所有依赖都正确安装，第3个cell应该可以成功运行了。
